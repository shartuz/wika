# Wika Dictionary

Personal English ~ Finnish dictionary and translator. It runs as an Android/iOS
app (Flutter + WebView) and as a plain website.

## Features

- **Dictionary search.** Type a word and press Enter. Suggestions appear as you
  type and tolerate small typos and missing accents (ä, ö).
- **Pinned search bar** with a home button that clears the search and returns
  to the top.
- **Notes, tables and pictures** for each entry, in English and Finnish.
- **Offline translator.** Word-by-word English ↔ Finnish lookup using about
  4,500 headwords in each direction. Works without internet.
- **Online translator (in the app).** Sentence translation through MyMemory.
- Dark glass theme, works on phones and desktops.

## Adding or editing a dictionary entry

Each entry in `assets/web/data/dictionary.json` looks like this:

```json
{
  "words": ["apple", "omena"],
  "translation": "omena",
  "englishDefinition": ["A fruit."],
  "finnishDefinition": ["Hedelmä."],
  "table": [["singular", "omena"], ["plural", "omenat"]],
  "imageName": "fruits.jpg"
}
```

- `words`: every search word that should find this entry (not case-sensitive).
  If a word is listed in more than one entry, all matching entries are shown.
- `englishDefinition` and `finnishDefinition` are lists. Each item is a line.
  Leave the list empty (`[]`) for no notes.
- You can format text with `<b>`, `<strike>`, `<red>`, `<green>`, `<blue>`,
  `<purple>` and `<yellow>`.
- `imageName`: a file in `assets/web/images/`, or `""` for no image.

Run `flutter test` afterwards. It checks that every entry has the right fields
and that every image exists.

## Running the app

Requires the Flutter SDK and Android Studio (or Xcode on a Mac for iOS).

```powershell
flutter pub get
flutter run               # on a connected phone or emulator
flutter test              # checks
flutter build apk         # Android release build
```

## How it works

The app starts a small web server inside the app, bound to `127.0.0.1` only.
Nothing outside the phone can reach it. The WebView loads the website from it,
so the dictionary works fully offline.

The **online** translator is the only feature that uses the internet. It sends
just the text you type into the translator to MyMemory
(`api.mymemory.translated.net`). The free limit is about 5,000 characters a day
and 500 bytes per request. Don't translate confidential text. The **offline**
translator only uses the word lists in `data/`.

## Hosting as a website

Upload the contents of `assets/web/` to any static web host. The dictionary
search and the offline translator work there, and so does "Add to Home screen".
The online MyMemory translator only works inside the app.
